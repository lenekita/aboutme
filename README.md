# Radu Nechita — Website Creator & Developer

A modern responsive portfolio website prepared for GitHub Pages.

## Files
- `index.html` — main website
- `style.css` — visual design and responsive layout
- `script.js` — menu, reveal animations and current year
- `assets/` — favicon and social preview image

## How to publish on GitHub Pages
1. Create a new GitHub repository.
2. Upload all files from this folder.
3. Go to **Settings → Pages**.
4. Select **Deploy from a branch**.
5. Choose `main` and `/root`.
6. Save.

Replace `https://your-domain.com` in `index.html` with your real portfolio URL when ready.
